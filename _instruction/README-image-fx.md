# Image FX — поява, 3D-нахил та лупа

Переносний attribute-driven модуль двох незалежних ефектів. Підключається
атрибутами; якщо їх немає на сторінці — скрипт **не потрапляє в білд**.

```
src/scripts/init/image-fx.js          — логіка
src/styles/components/_image-fx.scss   — стилі
```

## ⚠️ Підключення (обов'язково 2 речі)

**1. Скрипт** — уже зареєстрований в `app.js` умовно, нічого робити не треба.
Вантажиться лише якщо на сторінці є атрибути:

```js
// app.js (вже є)
if (document.querySelector("[data-image-fx], [data-reveal]"))
   tasks.push(import("@scripts/init/image-fx"));
```

**2. Стилі — треба підключити ВРУЧНУ** на кожній сторінці/в компоненті, що
використовує ефект. Без цього нахил/лупа/поява працювати НЕ будуть:

```astro
---
import "@styles/components/_image-fx.scss";
---
```

> Чому вручну: в Astro CSS прив'язується до сторінки на етапі білда. Якщо
> імпортувати SCSS у самому JS-модулі — CSS став би **глобальним** (потрапив би на
> всі сторінки). Імпорт у компоненті/сторінці тримає його **умовним** — лише там,
> де ефект реально використовується. Якщо ж хочеш 0 ручних імпортів — підключи
> `_image-fx.scss` один раз глобально (напр. у `BaseLayout`), ціною CSS на всіх сторінках.

Працює з SPA-переходами (`page:ready`) і поважає `prefers-reduced-motion`
(нахил/лупа/розмиття вимикаються, поява лишається простим fade). Нахил і лупа —
лише на пристроях зі справжнім hover (`pointer: fine`).

---

## 1. Поява при скролі — `data-reveal`

Елемент плавно з'являється (підіймається + fade), коли потрапляє у viewport.
Спрацьовує один раз.

```html
<div data-reveal>…</div>
```

| Атрибут              | Дефолт | Опис                         |
| -------------------- | ------ | ---------------------------- |
| `data-reveal-y`      | `28`   | висота підйому при появі, px |
| `data-reveal-dur`    | `0.7`  | тривалість, с                |
| `data-reveal-delay`  | `0`    | затримка перед появою, с     |

```html
<div data-reveal data-reveal-y="40" data-reveal-dur="0.9" data-reveal-delay="0.1">…</div>
```

> Без JS чи при `reduced-motion` елемент лишається видимим — прихований стартовий
> стан додається лише після того, як JS «озброїв» елемент.

## 2. 3D-нахил + лупа — `data-image-fx`

Вішається на **контейнер**, усередині якого є `<img>`. Модуль сам знайде картинку
та її обгортку. Нахил застосовується до **обгортки картинки**, а не до контейнера
(важливо, якщо контейнер має `backdrop-filter` — його трансформ щокадру дає фриз
на Safari).

```html
<div data-image-fx>
   <div class="img-wrapper"><img src="letter.png" alt="" /></div>
</div>
```

При наведенні:

- картинка **нахиляється** в 3D до курсора;
- за курсором іде **лупа** (прозоре коло, що збільшує ділянку картинки);
- решта картинки трохи **розмивається** → ефект «фокуса» (depth-of-field).

| Атрибут               | Дефолт    | Опис                                                            |
| --------------------- | --------- | -------------------------------------------------------------- |
| `data-fx-tilt`        | `11`      | макс. кут 3D-нахилу, deg (`0` = без нахилу)                     |
| `data-fx-smooth`      | `0.22`    | згладжування руху лупи `0..1` (менше = плавніше/інертніше)      |
| `data-fx-lens`        | `вимкнено`| **увімкнути** лупу (присутність атрибута = on; `="false"` = off)|
| `data-fx-zoom`        | `1.5`     | кратність збільшення лупи                                       |
| `data-fx-lens-size`   | `0.2`     | радіус лупи як частка меншого боку картинки                     |
| `data-fx-lens-edge`   | `72`      | м'якість краю: % де маска ще суцільна (далі згасає до прозорого)|
| `data-fx-lens-bg`     | `var(--color-bg)` | заливка лупи: **колір** або **CSS-градієнт** (має бути непрозорою) |
| `data-fx-blur`        | `2.5`     | розмиття картинки поза лупою, px (`0` = без розмиття)           |

### Чому лупа має непрозору заливку

Якщо картинка — **прозорий PNG** (напр. літера), то крізь прозорі ділянки
збільшеної копії просвічувала б оригінальна картинка під лупою → «роздвоєння».
Тому лупа малюється на непрозорому фоні (`data-fx-lens-bg`), який має збігатися з
фоном під картинкою. Для **фото** (непрозорі, на весь кадр) колір заливки не
важливий.

`data-fx-lens-bg` приймає не лише колір, а й **градієнт** — це для випадку, коли
фон картки не однотонний (як на `/alphabet`: градієнт сторінки крізь скло). Плоский
колір там давав би темний прямокутник на світлішій частині; градієнт зливається:

```html
<div data-image-fx data-fx-lens
     data-fx-lens-bg="linear-gradient(to top right, #0b111a 0%, #2a3a52 100%)">…</div>
```

> Це наближення (не піксель-у-піксель): живе семплування фону під лупою неможливе —
> `backdrop-filter` захопив би й саму картинку (роздвоєння) і дає фриз на Safari.
> Градієнт, що повторює напрямок фону картки, — найкращий практичний компроміс.

### Приклади

```html
<!-- тільки 3D-нахил (лупа за замовчуванням вимкнена) -->
<div data-image-fx>…</div>

<!-- нахил + лупа, сильніший і з більшим зумом -->
<div data-image-fx data-fx-lens data-fx-tilt="14" data-fx-zoom="1.8">…</div>

<!-- тільки чиста лупа, без нахилу й без розмиття -->
<div data-image-fx data-fx-lens data-fx-tilt="0" data-fx-blur="0">…</div>

<!-- лупа на світлому фоні картки -->
<div data-image-fx data-fx-lens data-fx-lens-bg="#ffffff">…</div>
```

## Поєднання

Атрибути незалежні — можна вішати разом (на різні елементи):

```html
<div class="row" data-reveal>
   <div class="card" data-image-fx>
      <div class="img-wrapper"><img src="letter.png" alt="" /></div>
   </div>
   <div class="text">…</div>
</div>
```

Приклад у проєкті — сторінка `/alphabet` (`src/pages/alphabet.astro`).
